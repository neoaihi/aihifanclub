Bluesky ブロック確認

ハンドルを入れると、そのアカウントをブロックしている人の一覧を表示します。ログイン不要です。

    あなたが入っているモデレーションリスト

    このリストを登録（ブロック）している人も、あなたをブロックしているのと同じ扱いになります。

      しくみと注意

      Bluesky のブロックは公開データ（app.bsky.graph.block）なので、誰が誰をブロックしたかは誰でも確認できます。このページは、ネットワーク全体のリンクを集計している公開サービス Constellation（constellation.microcosm.blue）に「このアカウントを対象にしたブロック」を問い合わせ、名前やアイコンを Bluesky の公開 API から取得しています。

      ・ブロックした日時はブロック記録の ID から計算した目安です。
      ・ブロック解除されたものは表示されませんが、反映まで少し遅れることがあります。
      ・「削除・停止済み」は、ブロック記録は残っているがアカウントが見つからない人です。
      ・ブロックリスト経由は、あなたが入っているリスト（最大500件まで確認）のうちモデレーションリストを登録している人を出します。
      ・入力したハンドルは Constellation と Bluesky の API にだけ送られます。履歴はこの端末のブラウザにだけ保存されます。
